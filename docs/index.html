STEP → Engineering Drawing

Upload a .stp / .step part or assembly and get a dimensioned drawing set back: orthographic views with hidden lines, model-selected dimensions, an assembly sheet with balloons and a bill of materials, as PDF and DXF.

Open the web app Source code

What you get

Part drawings

Front, top, side and isometric views per unique part, with hidden lines, center lines and a title block.

Smart dimensions

A trained model picks which sizes, hole diameters, positions and thread callouts (M2–M12) to show.

Assembly sheet

Repeated parts are grouped, ballooned and listed with quantities in a BOM table.

Correct units

Units are read from the STEP file (mm or inch) and printed on every sheet, with a manual override.

How to use it

  1. Open the web app.
  2. Drop your STEP file in and press Make drawings.
  3. Download the PDF, or the ZIP with DXF files (for AutoCAD, DraftSight, LibreCAD) and bom.csv.

Dimensions are chosen automatically. Check every drawing before using it for manufacturing. Very complex parts (castings, many features) are flagged and need manual cleanup.

Run it on your own computer

pip install -r requirements.txt
python convert.py mypart.stp              # command line
pip install gradio && python app.py        # same web app, at http://127.0.0.1:7860

On Windows you can also drag STEP files onto convert.bat.

Built with CadQuery / OpenCascade, ezdxf and scikit-learn.
